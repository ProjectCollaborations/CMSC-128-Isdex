# IsDex — Agent Instructions

## Project Overview

Flutter fish-sighting app backed by Firebase Auth + Realtime Database (RTDB, not Firestore).

## Setup

1. `flutter pub get`
2. Copy `.env.example` to `.env` and fill in `GEMINI_API_KEY` and `IUCN_API_TOKEN`
3. Ensure `google-services.json` (Android) / `GoogleService-Info.plist` (iOS) are present (gitignored)
4. `lib/firebase_options.dart` is generated by FlutterFire CLI — do not edit manually

## Commands

| Task | Command |
|------|---------|
| Lint / analyze | `flutter analyze` |
| Run app | `flutter run` |
| Run tests | `flutter test` |
| Build | `flutter build <platform>` |

## Architecture — MVVM migration in progress

**Current state**: Smart UI pattern — screens in `lib/screens/` call Firebase directly. No models/, viewmodels/, or repositories/ exist yet.

**Target**: MVVM + Repository (see README for full folder mapping). New code MUST follow the MVVM layout (`lib/models/`, `lib/viewmodels/`, `lib/views/`, `lib/core/`). When editing an existing screen that hasn't been migrated yet, match the surrounding Smart UI style until that screen is formally migrated.

The project is actively migrating from Smart UI to MVVM. Do not add new Smart UI screens.

## Key conventions

- Firebase RTDB node names are managed as string constants spread across screen files. During MVVM migration, consolidate into `core/constants/firebase_nodes.dart`.
- `AuthService._emailKey()` replaces `.` with `,` in email addresses for safe RTDB paths — this is intentional.
- `AppConfig` in `lib/config/app_config.dart` can receive `IUCN_API_TOKEN` via `--dart-define` at build time as an alternative to `.env`.
- Fish image assets live in `assets/images/fish/`; declare new ones under `flutter.assets` in `pubspec.yaml`.

## Agent-generated files

Any files created by agentic tools that are not part of the project itself (e.g., temporary scripts, scratch files, debug logs) must be added to `.gitignore` immediately. Never leave agent artifacts untracked.

## Testing

Tests are placeholder-only (`test/widget_test.dart`). Firebase must be initialized or mocked for meaningful tests.
